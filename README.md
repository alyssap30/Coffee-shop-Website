## Project Overview 

 I created an application for a mock up coffee shop allowing for customers to order food, view current job opening and create an account. The application allows for users to select the quantity of each item, view the table summary of items and then pay. Also on the "About Us" page I have added job listings with a built in application form.

## Features

- Event Listeners
- The use of classes
- Random password generator 
- Mathematical Calculations
- Mobile Compatibility
